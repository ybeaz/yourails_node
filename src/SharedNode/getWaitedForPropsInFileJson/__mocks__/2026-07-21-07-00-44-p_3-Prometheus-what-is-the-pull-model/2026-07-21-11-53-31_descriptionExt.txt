### 00:30 Understanding the Pull Model
Summary:
- Prometheus scrapes targets actively
- No need for agents on target systems
- Targets expose metrics at endpoints
- Centralized data collection approach// Prometheus Pull Model
 prometheus.scrape(
   target.endpoint()
 );
 // No agents needed
 target.exposeMetrics();
 // Centralized collection
